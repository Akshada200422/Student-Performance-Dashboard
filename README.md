Student Performance Dashboard (Power BI)

An interactive Power BI dashboard that analyzes student performance across classes, subjects, exam months, gender, and admission stages. It helps educators and administrators track academic results and attendance trends and spot areas that need attention.

Project Overview

The dashboard covers 1,000 students and brings together marks, attendance, pass/fail results, gender distribution, and admission-stage data in a single view. Slicers let users filter the data and explore it from different angles.

📊 Key Metrics

| Metric | Value |
|---|---|
| Total Students | 1K |
| Total Marks | 66 |
| Total Attendance | 41 |
| Count of Result | 1K |

Dashboard Features

- **Filters:** Class, Subject, Exam Month, City, Result, and Gender
- **Students by Class:** Bar chart showing student strength from 6th to 12th
- **Result Analysis:** Donut chart of Pass (932) vs Fail (68)
- **Subject Performance:** Total marks for English, Geography, Maths, and Science
- **Gender Distribution:** Male (508) vs Female (492)
- **Class × Gender Matrix:** Student breakdown by class and gender
- **Admission Funnel:** Students by stage (Inquiry, Fee, Counselling, Registration, Admission)
- **Monthly Trends:** Marks, attendance %, and student count by exam month
- **Student Detail Table:** Student ID, name, class, gender, subject, and attendance

Key Insights

- The overall pass rate is about **93.2%**, with a fail rate of about **6.8%**
- The gender split is nearly even (50.8% male, 49.2% female)
- Total marks and attendance show a **gradual decline** across exam months
- English and Geography have the highest total marks among the subjects
- The Inquiry stage has the most students in the admission funnel (216), and Admission has the fewest (180)

Tools Used

- **Power BI Desktop** for data modeling, visualization, and slicers
- **Excel/CSV** as the data source

How to Use

1. Download `Student_Performance_Dashboard.pbix` from this repository
2. Open it in **Power BI Desktop**
3. Use the slicers (Class, Subject, Exam Month, City, Result, Gender) to filter the data
4. Click on any chart to cross-filter the other visuals

If you only want a quick look, open the PDF.
